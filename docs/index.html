How it works

One catalog for registered and discovered agents.

Agent 365 knows what is running in your tenant. AI Agent Central knows how it should be governed. The integration joins the two, so your readiness assessments, owners, and KPIs sit against the live estate instead of a stale list.

  • Bring the Agent 365 agent inventory into the AI Agent Central catalog
  • Open a full detail view for any Agent 365 agent without leaving the app
  • Attach readiness assessments, goals, and activities to discovered agents

Stage 1

Deploy the Power Platform environment

Provision the environment that will host the Dataverse database and AI Agent Central app.

01
Power Platform

Environment with Dataverse

Create the environment, enable Dataverse, assign roles, and turn on Power Apps Code Apps.

⏱ ~10 min
1
Sign in to the Power Platform Admin Center using your System Administrator credentials.
2
Click Manage > Environments and select New.
3
Choose the appropriate environment type.
Tip: A Developer environment includes Dataverse and is ideal for individual use and testing.
4
Provide a name and region, select Dataverse as the database option, and click Next.
5
If you selected Sandbox or Production, provide the Entra security group name that will have access to this environment.
6
Once created, open the environment's settings. Under Users, add users who need access and assign them the App Opener role (or an equivalent security role) so they can launch apps.
7
Go to Settings > Features, locate Power Apps Code Apps, and enable it so users can build and run code-based apps.
Stage 2

Import the solution

Bring the AI Agents Governance Hub solution package into your environment.

02
Solution

Import AIAgentsGovernanceHuB package

Upload the solution ZIP, resolve connections, and configure environment variables.

⏱ ~10 min
1
Navigate to make.preview.powerapps.com.
2
Click Environments and select the appropriate environment.
3
In the left navigation click Solutions, then Import solution from the toolbar.
4
Download the latest solution package · coming 1 September 2026, then click Browse, select the AIAgentsGovernanceHuB_1_0_0_72.zip file, and click Next.
5
Click Next on the review solution details page.
6
Resolve any missing dependencies or connection conflicts before proceeding, then click Next.
7
Configure the Teams ID and Channel ID environment variables, then click Import.
8
Wait for the import to complete.
Typical import time is 5-10 minutes.
9
Verify the solution components and ensure everything deployed as expected.
03
Access

Share app access

Grant your AI CoE team access to the AI Agent Central app.

⏱ ~5 min
1
Navigate to make.preview.powerapps.com and confirm the correct environment is selected.
2
Click Apps in the left side navigation menu.
3
Select the AI Agent Central app and choose Share > Share.
4
Add the members of your AI CoE Team and select the AI Hub Users permission.
Stage 3

SharePoint site for pillar evidence

Create the communication site that will store evidence documents and usage exports.

04
SharePoint

Create site & document libraries

Provision a Communication site with two libraries: Evidence and Usage.

⏱ ~5 min
1
Navigate to your SharePoint admin center at https://tenant-admin.sharepoint.com.
2
Click Active Sites in the left navigation.
3
Click Create site and choose Communication site.
4
Enter a site name, description, and your preferred settings, then click Finish.
5
Open the site's homepage and click Site contents in the left navigation.
6
Click New > Document Library, name it Evidence, and click Create.
7
Repeat the previous step to create a second library named Usage.
8
Both libraries will now appear in your site contents, ready for document uploads and management.
05
Usage Data

Export the M365 agent usage report

Download the Users & Agents CSV from the M365 admin center and upload it to SharePoint.

⏱ ~3 min
1
Navigate to M365 Copilot Declarative Agents report.
2
Scroll down to the Usage Details section and select Users & Agents.
3
Click Export and save the file as Agents_Users_Usage.csv.
4
Upload the saved file to the SharePoint Online Usage library created in the previous stage.
06
Dataflow

Configure the usage data import

Point the Power Platform dataflow at your SharePoint site so it can ingest the usage CSV.

⏱ ~5 min
1
Navigate to make.preview.powerapps.com.
2
In the left navigation click Dataflows (or More > Dataflows).
3
Click Edit to configure parameters.
4
Configure the SPO Site as https://<tenant>.sharepoint.com/sites/<site_name>.
5
Leave the CSV file name unchanged if you saved your usage file as Agents_Users_Usage.csv.
6
Configure the folder path as https://<tenant>.sharepoint.com/sites/<site_name>/Usage.
7
Click Query > Configure connection.
8
Authenticate (Connect) and confirm that data is loading.
9
Click Next, then Publish.

Stage 5

First steps inside the app

Configure your organization's foundation - business units, goals, and KPIs - before onboarding teams.

10
In-App Setup

Business Units, Goals, and KPIs

Lay down the organizational structure and the AI outcomes you'll measure against.

⏱ ~10 min
1
Go to Settings > Business Units and add your organization's business units (Communications, Strategy, Support, Engineering, etc.).
2
Go to AI Goals and add your strategic goals - for example, increasing annual revenue, retaining customers, or improving operational efficiency.

For each goal, add one or more related KPIs covering revenue growth, profitability, and other business metrics that AI agents should influence.
Tie every agent to at least one goal so leadership rollups stay accurate
Use RAG status on KPIs to surface delivery health at a glance
Revisit goals quarterly to keep the portfolio aligned with strategy

Two ways to use them

Bring your own, or start with ours

The templates are a starting point - never a requirement. Use whichever path matches the maturity of your AI program.

◆

Start with the templates

Best for organizations standing up agent governance for the first time, or teams that want a structured, framework-aligned baseline.

  • Download the ZIP and unpack the 5 .docx files
  • Fill in each pillar with your organization's information
  • Upload completed docs to the SharePoint Evidence library
  • Run the AI Agent Assessment agent
●

Use your own artifacts

Already have strategy docs, process maps, architecture diagrams, or governance policies? Keep using them - just place them in the Evidence library.

  • Upload your existing PDFs, Word docs, or wiki exports
  • Group them by pillar in the Evidence library folders
  • Reference the templates above as a coverage checklist
  • Mix and match - some pillars yours, others from the templates
